# 分析方法库与指标口径（股票分析 skill 专用）

历史项目验证过的分析方法与口径。所有金额默认人民币；回测均为税前、未计滑点。

## 1. 公司估值（个股深度报告必做 ≥3 种方法交叉验证）

| 方法 | 口径与要点 |
|---|---|
| 相对估值 | PE(TTM) / PB / PS 与自身历史 5 年分位、同业横向对比；周期股 PE 失真时以 PB 为主 |
| 历史 PE/PB 分位 | 用周频复权数据算 1y/3y/5y 分位，报告须给出区间（如近5年 2.17~7.23 倍） |
| EV/EBITDA | 不含租赁口径 EV=市值+有息负债-货币资金；含租赁口径加使用权负债；酒店等重资产行业给行业 8~10 倍参照 |
| SOTP 分部估值 | 按分部盈利×分部 PE，或净资产×折价系数（如建材 0.40~0.70xPB、地产 0.45~0.75x），合并扣总部净负债；每情景给保守/中性/乐观三档并给权重 |
| DCF | 以经营现金流-资本开支为 FCF，预测期 10 年，WACC 8%~10%，永续增长 1.5%~2%；**必须做资本开支强度敏感性**（如 40%/50%/60%），酒店/养殖等资本开支波动大的行业尤甚 |
| DDM/股息估值 | 每股股利 ÷ 目标股息率；目标股息率 3.5%（低风险国企）~5.5%（风险补偿） |
| 周期股专用 | 周期平均盈利法（完整周期平均净利×PE）、重置成本法（养殖股：产能×每头成本 2500~4000 元）、猪价情景法（出栏×头均重×（猪价-成本）） |
| 综合结论 | 多方法加权（给权重并说明），输出合理区间+中枢+相对现价空间 |

## 2. 网格交易回测（震荡市/周期股专用）

- 核心参数：基准价、网格区间（常取现价 ±20%）、间距（% 或元）、每格股数、底仓比例（50%~60%）
- 回测规则（历史实现已验证）：
  - A 股 T+1：当日买入批次当日不可卖
  - 路径假设：当日收盘≥开盘按"先触低后触高"，反之先高后低；成交价=网格线价
  - FIFO 批次核算实现利润
  - 费用：佣金 万0.9（不免5，单笔最低 5 元）+ 卖出印花税 0.05%；往返成本率稳定值 0.068%（每格≥5.6 万元时）；盈亏平衡成交额 = 5 ÷ 0.00009 ≈ 55,556 元
- 输出：参数扫描热力图（间距×每格 vs 超额收益）、MC 箱线图（GBM 500 路径、漂移 ±60%/~30%/0），结论按市况给胜率（下跌市 77~83%、震荡 65%、单边上涨 34%）
- 适用性判断：网格牺牲趋势收益换震荡收益；单边市跑输买入持有——报告必须给出市况适配结论

## 3. 定投（DCA）回测（指数/基金）

- 触发模型：PE 百分位触发（如 30% 以下开始定投，50% 以上停止并分批卖出）；窗口 3y/5y/10y/全部对比
- 模式：B 模式（低估区间持续定投）、C 模式（回撤触发/峰值后 N 个月入场）
- 指标：XIRR、最大回撤 MDD、胜率、期末金额 vs 一次性投入
- 加仓节奏：等额 M0 / 分批 M1~M6 / 加速金字塔（跌越深买越多 L50/L40/L30）对比；区分月度预算框架与存量资金框架
- 数据：指数日线 + 乐咕 PE 序列合成 master 表（date, close, pe）

## 4. 板块/股票池筛选（主题研究）

- 输入：股票池（代码+名称+板块），东财批量行情快照
- 指标：PE(TTM)、PB、PS、换手率、5 日动量、总市值；行业板块 PE/PB 作参照
- 分类规则：龙头（市值+盈利+动量领先）、热门（换手率高/涨幅大）、亏损（净利<0）、关注（其他）；分板块横向对比
- 输出：散点图（PS vs 换手，气泡=市值）、跨板块 PE/PB/换手柱状面板

## 5. 指数增强基金筛选

- 全市场基金池 → 按 8 大指数类别分组 → 抓 NAV 历史
- 三周期排名：1 年/2 年/3 年同类排名均进入前列（如前 30%）才入选
- 月度排名稳定性（跟踪期 12~24 月）、超额收益持续性、费率（管理+托管）、规模（>2 亿防清盘）、经理任职年限
- 加权评分推荐 Top3；与被动指数基金对比（超额 alpha、跟踪误差、回撤）

## 6. AH 溢价/AB 股/港股红利

- AH 溢价：同股同权标的 A/H 价格比（东财 AH 溢价地图或自抓 A 股行情+H 股行情），统计溢价分布、高低溢价组回测
- AB 股：A/B 股名单（新浪接口）、配对折价率=1-B价/A价（美元 B 股需汇率换算），折价历史回测
- 港股红利：指数官方（恒指公司/CSIndex）年化回报、股息率隐含策略

## 7. 红利资产/利率敏感性

- DDM：红利指数合理点位 = 分红基数 ÷（目标收益率-分红增速）
- 回归：指数股息率 vs 10 年国债/美债收益率利差
- 压力测试：无风险利率 +50/100bp 情景下的股息率保护垫
- 牛熊判定：红利牛（2021—2024）持续性用分年收益率、指数间相关性检验

## 8. 牛熊周期识别（指数择时）

- 峰值识别：长周期均线（MA250/周线）上下穿越 + 波段极值
- 阶段统计：上涨/下跌周期持续时间、振幅、熊市长度 vs 上涨幅度回归
- 估值联动：周期位置 vs PE 分位；FFT 谱分析周期成分（历史项目用 cyc_spectral）
- 反转点：估值分位极值 + 月度收益序列的双重确认

## 9. 商誉/减值专题（财报深挖）

- 数据：年报 PDF（巨潮）商誉附注 + datacenter F10 商誉原值/减值准备/净值
- 核查：减值准备明细表（年度×标的×金额）、商誉变动路径（并购+汇率+处置转出+减值）
- 风险量化：测试余量=（可收回金额-资产组账面价值）；触发阈值=可收回金额需下降 %；敏感性（收入假设/折现率/汇率）
- 情景测算：减值对净资产、PB、ROE 的冲击表；区分账面冲击与现金流影响

## 通用规范

- 数值口径在报告附录注明；估算值标注（估）；比率保留 2 位小数、金额用万元/亿元
- 每份报告必须含：数据来源、关键假设、风险提示、免责声明
- 图表全部以中文字体（微软雅黑）输出 PNG，统一命名 `figN_主题.png`
