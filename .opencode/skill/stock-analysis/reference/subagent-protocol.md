# 子代理协议与上下文防火墙

铁律：主上下文=纯编排器，不产分析文本、不转述数字；数字只经算子库与落盘文件流动。每报告子代理 ≤3：数据侦察兵×1、写手×1（全稿）、审计员×1；PUA 由主上下文完成，不派子代理；/ask self-grill 的拷问者/应答者属命令级，不计入配额。

## 输入包

- = 3~8 个已登记文件路径（`WORKSPACE.md`）+ 任务模板路径 + 输出落盘路径
- 禁目录级投喂、禁塞主上下文摘要；输出=落盘文件+结构化 JSON 摘要
- 导航只读 `_registry.json`（跨报告）与 `WORKSPACE.md`（报告内）；按需读，禁全库扫描，只用已登记路径

## 角色与隔离

| 角色 | 输入 | 隔离要点 |
|---|---|---|
| 侦察兵 | brief 字段+推导源集 | 不知论点/结论；只产 `00_cache/*` 与 `10_facts/FACTS.md`（纯数字+来源+口径，禁解读） |
| 写手 | 蓝图+thesis+FACTS+该稿数据文件 | 禁自行抓数（四眼原则）；按蓝图 sections 顺序写全稿；提交前蓝军自攻 |
| 审计员 | 全文 dump+thesis.json+failure_criteria | 全新上下文，唯一全稿对抗角色；R1 定案，仅 revise 击穿假设才回流，full 级加 R2 只核修正处 |
| 主上下文 PUA | 全稿+thesis | 全稿 checkpoint 一次：先自攻验证 → ≤3 专业问+≤1 通俗问；驳回重写 ≤1 次（换角度），二次转审计 |

## 写手蓝军自攻（SELF_ATTACK 块 3 问）

1. 空头一击：≥2 条最致命攻击+防御/承认
2. 最心虚数字：口径/时点/单位最可能错在哪，逐个点名
3. 动机性推理自检：是否先结论后证据；反方证据主动找过吗

红线：数字→文件→字段闭环；未验证"常识"禁用；自攻敷衍（"没问题"式空话）打回。

## FACTS 冻结

1. 侦察兵产 `10_facts/FACTS.md`：指标|数值|口径|asof|来源文件，禁解读
2. 建模前冻结；缺数据→新开侦察补条，禁写手/预测者边写边抓
3. 建模与写作只消费 FACTS+算子输出

## 异常归宿（绝不悬停）

| 异常 | 路径 |
|---|---|
| PUA 驳回 | 自动重写 ≤1 次 → 转审计未决 |
| 审计 revise | H1 回流重跑 forecast_lib→valuation_lib→更新树（full 加 R2） |
| 数据失败 | 降级标注/盲点清单（`spot_price` 等返回 None 须明示） |
| 轮次/预算超限 | `workspace_lib.blocked(no, 卡点, '/report resume no')` |
